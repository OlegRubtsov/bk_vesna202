# Плеер БК0010...11М

ESP32-C3 воспроизводит BIN-файлы через магнитофонный вход БК-0010 и БК-0011М. Управлять плеером можно из браузера или кнопками на плате. Файлы хранятся во встроенной памяти.

**В прошивку встроен один файл — `bk0010.bin` (8 284 байта).** На устройстве с пустой файловой системой только он доступен в списке «Файл BIN». Плеер отмечает его звёздочкой и защищает от удаления. Остальные BIN появляются после загрузки пользователем и хранятся в LittleFS. Записи в «Сохранённых ссылках» указывают, откуда можно скачать файл. Сам BIN занимает место в LittleFS только после загрузки.

## Подключение и первый запуск

| Назначение | Подключение ESP32-C3 |
| --- | --- |
| OLED SSD1306, 128×64, адрес `0x3C` | SDA — GPIO5, SCL — GPIO6 |
| Выход магнитофонного сигнала | GPIO8, общий GND с БК |
| Кнопка 1 — предыдущий файл | GPIO0 |
| Кнопка 2 — пуск / стоп | GPIO1 |
| Кнопка 3 — следующий файл | GPIO2 |
| Кнопка 4 — меню / выход | GPIO3 |

Каждая кнопка при нажатии замыкает свой GPIO на GND. Все четыре входа используют внутреннюю подтяжку.

При запуске плеер открывает точку доступа **BK_PLAYER** без пароля. Подключитесь к ней и откройте [страницу плеера](http://192.168.4.1/), если браузер не открыл её автоматически. Для подключения к домашней сети выберите **Настройки Wi-Fi**, введите имя сети и пароль. Плеер хранит их в настройках ESP32-C3. При следующем запуске он отводит до 15 секунд на подключение к сохранённой сети. IP-адрес для доступа из домашней сети показан на OLED.

## Воспроизведение

В режиме остановки нажмите кнопку 4 для входа в меню. Кнопками 1 и 3 выберите параметр, кнопкой 2 начните редактирование. Измените значение кнопками 1 и 3 и подтвердите кнопкой 2. Кнопка 4 закрывает меню и отменяет неподтверждённое изменение.

В меню доступны скорость (1,0–3,0× с шагом 0,5×), уровень сигнала (0–100%, шаг кнопки 5 процентных пунктов), замена имени в заголовке и перевод имени в верхний регистр. Для переключателей кнопка 1 выбирает OFF, кнопка 3 — ON. Имя для замены по умолчанию — латинская `V`. Сам текст можно изменить в веб-интерфейсе. Сохранённые параметры действуют при запуске как с платы, так и из браузера.

Короткое нажатие кнопки 1 или 3 перемещает выбор на один файл. Если удерживать кнопку, через 0,5 секунды начнётся прокрутка с шагом 180 мс. Отпускание останавливает прокрутку и сохраняет выбор. Для кнопки 2 действует одно переключение «Пуск / Стоп» за нажатие.

На плате кнопками 1 и 3 можно листать по кругу список локальных BIN. OLED показывает выбранное имя и позицию, например `FILE 2/5`. Кнопка 2 запускает выбранный файл с уровнем сигнала и скоростью, сохранёнными через веб-интерфейс. Во время передачи OLED показывает полосу прогресса, процент и оставшееся время. Чтобы выбрать другой файл до окончания передачи, сначала остановите её кнопкой 2.

1. Выберите файл в списке **Файл BIN** или нажмите **Загрузить** и выберите локальный `.bin`. Максимальный размер файла с заголовком — 65 539 байт.
2. Выберите скорость от 1,0× до 3,0× с шагом 0,5×. При необходимости отрегулируйте **Уровень сигнала** или задайте имя в заголовке ленты.
3. Нажмите **Пуск**. В поле выбранного файла появятся процент воспроизведения и оставшееся время. Кнопка **Стоп** прерывает передачу.

Свободное место в LittleFS показано в веб-интерфейсе. При нехватке места плеер удаляет самые старые пользовательские BIN, разрешённые к автоудалению. Чтобы сохранить файл, выберите его и включите **Не удалять автоматически при загрузке новых BIN**. Скрепка в списке показывает, какие файлы защищены.

## Онлайн-каталог

Выберите запись из **Сохранённых ссылок** или вставьте ссылку на BIN, ZIP либо страницу каталога и нажмите **Скачать и запустить**. Браузеру нужен доступ к источнику файла. Если в ZIP несколько BIN, выберите нужный и нажмите **Распаковать и запустить**. Плеер сохранит выбранный BIN и начнёт воспроизведение.

Если в LittleFS ещё нет `catalog_links.txt`, прошивка создаёт его с одной [начальной ссылкой на каталог БК](https://kalininskiy.github.io/bk-catalog/#game-738). Чтобы использовать [список из репозитория](catalog_links.txt) или собственный список, нажмите **Загрузить список ссылок** и выберите TXT. Загруженный список заменяет текущий. Кнопка **Скачать список ссылок** сохраняет его под именем `catalog_links.txt`.

В TXT допускается до 3 000 ссылок, по одной на строку. Формат записи — `URL;отображаемое имя`. Имя может быть на русском языке. Если указать только URL, плеер возьмёт имя из ссылки.

## Сборка и прошивка

Проект использует PlatformIO с профилем платы `esp32-c3-devkitm-1`. Подключите плату по USB и выполните команды из корня проекта.

```powershell
pio run -e esp32-c3-oled
pio run -e esp32-c3-oled -t upload
```

В сборку входит [reference/bk0010.bin](reference/bk0010.bin). Его напрямую подключает [src/system_bin.S](src/system_bin.S).

Тестовая конфигурация `esp32-c3-autotest` при старте запускает первый пользовательский BIN из LittleFS на скорости 3,0× и пишет ход передачи в последовательный порт (115 200 бод). Для этого теста предварительно загрузите хотя бы один BIN через веб-интерфейс.
