# BK BIN tape player for ESP32-C3

Проигрыватель файлов BIN для БК-0010/БК-0011. Все 25 BIN-файлов из `reference` (304 980 байт суммарно) встроены во flash и доступны в веб-интерфейсе без SD-карты. Формат сигнала использует штатную структуру магнитофонной записи БК: калибровочный участок, синхромаркеры, заголовок, данные и контрольную сумму.

## Подключение

- Большой OLED SSD1306 128×64, адрес `0x3C`: SDA GPIO5, SCL GPIO6.
- Аудиосигнал: GPIO8. Общий GND ESP32-C3 и входа магнитофона БК.
- Кнопки и SD-карта плеером не используются.

GPIO8 сейчас занят пищалкой. Для подачи сигнала на вход БК подключите аудиопровод к GPIO8 и GND; вход БК должен получать переменный аудиосигнал. При необходимости используйте разделительный конденсатор и последовательный резистор. Пьезопищалку лучше отсоединить на время проверки уровня сигнала.

## Управление

Плата подключается к Wi-Fi, заданному в `include/secrets.h`. После загрузки откройте IP-адрес, показанный на OLED, в браузере. Выберите BIN и нажмите **Play**; **Stop** немедленно выключает аудиовыход. На странице и дисплее отображаются состояние Wi-Fi, процент переданных данных и примерное оставшееся время. В форме **Upload BIN** можно загрузить дополнительный BIN: он сохраняется во flash-файловой системе и появится в списке. Встроенные файлы отмечены `*` и не удаляются; загруженный BIN можно удалить кнопкой **Delete selected**. Устройство проверяет заголовок файла; размер одного файла — не более 65 539 байт, а для воспроизведения он целиком загружается в RAM.

Раздел приложения занимает 1 310 720 байт; текущая сборка использует 1 144 350 байт, свободно примерно 162 KiB для будущего роста встроенной прошивки. Для пользовательских BIN выделен отдельный раздел LittleFS на 1 441 792 байта (1,375 MiB); точный остаток с учётом файловой системы показывается в веб-интерфейсе.

Все файлы с расширением `.bin` (без учёта регистра) из `reference` включаются автоматически скриптом `python tools/embed_bins.py`. После добавления или замены BIN запустите скрипт и пересоберите прошивку. Данные BIN начинаются с адреса и длины загрузки в little-endian; после 4-байтового заголовка следует полезная нагрузка.

## Сборка и прошивка

Проект собирается PlatformIO для `esp32-c3-devkitm-1`. Загрузка на плату, определённую как COM10:

```powershell
pio run -e esp32-c3-oled
pio run -e esp32-c3-oled -t upload --upload-port COM10
```

Автотестовая сборка `esp32-c3-autotest` автоматически проигрывает `bk0010.bin` и печатает по COM прогресс, число бит и фактическое время передачи.

## Загрузка BIN из онлайн-каталога

В веб-плеере вставьте прямую ссылку на `.bin` из `kalininskiy.github.io/bk-catalog` и нажмите **Download and Play**. Страница каталога открывается кнопкой **Open BK catalog**. Ссылка GitHub Pages автоматически преобразуется в URL файла GitHub Raw: браузер скачивает BIN по HTTPS, отправляет его плееру, после чего файл сохраняется в LittleFS и начинает играть с выбранной скоростью. Поддерживаются отдельные BIN размером до 65 539 байт; ZIP-архивы распаковываются в браузере; если внутри несколько BIN, плеер предложит выбрать файл. 7z пока не поддерживается. Если браузер запрещает загрузку по CORS, скачайте файл вручную и используйте **Upload BIN**.


Формат catalog_links.txt: одна ссылка на строку в виде URL;отображаемое имя. Если имя опустить после точки с запятой, интерфейс возьмёт имя файла из ссылки. В список по умолчанию входят BK3D10.bin и архив tron1b72.zip. Загрузите свой .txt, чтобы заменить список; ссылки и имена проверяются и сохраняются в LittleFS. Выбор строки заполняет поля имени и URL, которые можно изменить перед запуском.
